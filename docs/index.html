applyr

A Chrome extension that fills job applications from one profile you control. No account, no server, no telemetry.

Install from GitHub
  • 11 ATS packs — Lever, Greenhouse, Ashby, Workable, SmartRecruiters, Pinpoint, JazzHR, Recruitee, BambooHR, Workday, iCIMS
  • Generic mode — falls back to label matching on any other career site
  • Job board ranking — scores Naukri listings against your profile
  • Question memory — learns screening answers and recalls them across employers
  • 100% on-device — no network requests unless you opt into selector updates
  • Never submits — fills, verifies, and reports; you click Submit
