applyr fixtures

Offline stand-ins for the real boards, so the fill engine can be exercised without sending anything to a real employer. Serve them over HTTP with npm run serve, then grant applyr access to http://localhost:5173 from the side panel.

Lever-like Single full-name field, bracketed urls[LinkedIn] names, plain file input. Greenhouse-like Stable ids, radio groups for work authorisation, EEO selects, react-select combobox. Hard mode Controlled input that reverts naive writes, a field in a shadow root, a portalled listbox, and a second wizard step created on demand. Workday-like The six-step apply flow: an account gate that must not be filled, then data-automation-id fields and a date split across three boxes. Generic / unknown ATS Opaque field names and label-only matching — what generic mode has to cope with.
